# README visuals

These assets contain no commercial-game imagery or game data.

- **hero.webp** — original editorial controller illustration generated with
  OpenAI's built-in image-generation tool. Three directions were compared and
  the editorial version was refined. Illustrative, not a screenshot or a diagram
  of the exact network. Provided under the project's MIT terms.
- **desktop-gallery.webp** — actual native AgentEmu gallery capture on macOS.
- **mobile-shared.webp** — actual browser UI at a 390 × 844 viewport. This is a
  responsive-layout capture, not a claim of physical-phone acceptance.
- **shared-setup.gif** — actual browser recording: choose Contra, select Shared
  for player 1, then No player 2. No ROM was loaded. The recording shows setup,
  not gameplay, inference or evidence of model quality. It has no game audio.
- **neural-inputs.svg** — original vector diagram of the bundled Contra Jungle
  policy. Counts follow `integrations/contra-jungle/observation.json` and the
  fixed actor architecture. Other games have their own observation contracts.

Interface captures use the original gallery title cards generated by
`scripts/generate-artwork.py`. IBM Plex Sans retains its SIL Open Font License;
see `crates/player-ui/assets/OFL.txt`. Game names identify compatibility; no
endorsement or affiliation is implied. Image digests and sources are recorded
in `provenance.json`.
