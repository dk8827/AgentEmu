# Changelog

## 0.1.0 — initial source release

- Original Rust NES core, shared native/browser Rust UI and mobile touch controls.
- Human, AI and Shared control, with per-group ownership and stage handoffs.
- Bundled neural agents for six games; native training and evaluation tools.
- Local sound, battery saves, save slots, controller replays and compatibility evidence.
- Fresh AgentEmu source snapshot with MIT code/model licensing.

This release provides source and model weights. Mobile, physical gamepad and
accessibility acceptance remain pending; see [release scope](docs/RELEASE.md).
No signed installers or hosted service are provided.
